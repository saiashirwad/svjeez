# svjeez starter

`scene.tsx` is a scene: a curve draws itself, a dot pops in and a word sits below. Edit it and the preview reloads.

```sh
npm run dev     # live preview with a scrubber
npm run check   # problems with file:line and a fix
npm run svg     # writes scene.svg
```

Geist is under the SIL Open Font License, in `fonts/Geist-OFL.txt`.
