svjeez

Write a scene in TSX. Get one animated SVG that plays in an image tag.

Free and open source · No JavaScript in the output · Node 20 or newer

Motions on a timeline

Chain .at(), .to() and .wait() on one timeline. Opacity, position, scale, color and stroke drawing all compile to CSS keyframes.

Diagrams that build themselves

Flowcharts, sequences, trees and state machines from a typed spec. A misspelled id is a compile error, not a blank box.

Code explainers

Type code out, move a spotlight across it and pin a note to any token.

Terminal recordings

A shell session typed out with its output, as a file you can embed anywhere.

Ink and handwriting

Brush, nib and pencil strokes, and single-line fonts that write themselves.

Light and dark

One file carries its own prefers-color-scheme rules. The page only says which one applies.

Motions are values on a timeline.

Write the chain once. The compiler turns it into CSS keyframes, so nothing runs in the viewer's browser.

Diagrams that build themselves.

Give it nodes and edges. It lays them out, reveals them in order and sends a packet along any route.

Explainers and terminal recordings.

Code that types itself, a spotlight that follows the explanation, and a shell that prints what the real one would.

Your fonts. Your ink.

Embed a font and it is cut down to the glyphs you use. Write by hand with a brush, a nib or a pencil.

One file. It changes its own mind.

The two halves below are the same daynight.svg, fetched once. One <img> is told the page is light, the other that it is dark. The scene decides what to show.

lightdark
  • A media query inside the fileThe scene carries @media (prefers-color-scheme) rules. The page only says which scheme applies.
  • Not a recolorThe sun is a moon, windows light up, a beam sweeps the water. The scene swaps whole parts.
  • Use the toggle at the topIt flips the whole page, and every scene on it follows.
const { theme, css } = adaptive({
  dark: tomorrowNight, light: tomorrow,
});
// theme colors are CSS variables
render({ css }, <rect fill={theme.base00} />);

Agents write scenes too.

Install the skill once. A coding agent then reads it, writes a scene, renders frames, looks at them and fixes what it sees.

Not a JSX fan? Use functions.

Every element is also a function. Set prefix and the file can be inlined next to others, in a view library such as FoldKit, without id clashes.

Anywhere an image works.

Install it, then ask for a scene.

In a project

npm i svjeez
npx svjeez frames scene.tsx --sheet
npx svjeez svg scene.tsx --out scene.svg

TypeScript, no dependencies, Node 20 or newer.

With a coding agent

npx svjeez skill --install

Copies a skill and worked examples into .claude/skills, so the agent knows how to write, render and check a scene.
