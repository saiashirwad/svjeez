TSX in.
One SVG out.

svjeez compiles a scene written in TSX into one animated SVG. Motion becomes CSS keyframes, so nothing runs in the viewer's browser and the file plays in a plain image tag.

$ npm i svjeez

See the examplesSource on GitHub

01Motions on a timeline
Chain .at(), .to() and .wait() on one timeline. Opacity, position, scale, color and stroke drawing all compile to CSS keyframes.
02Diagrams that build themselves
Flowcharts, sequences, trees and state machines from a typed spec. A misspelled id is a compile error, not a blank box.
03Code and terminals
Explainers with a spotlight and notes pinned to tokens, and shell sessions that print what the real one prints.
04Ink, type and light
Brush, nib and pencil strokes, fonts embedded and cut down to the glyphs you use, and one file that follows light and dark.

01 Motion

Motions are values on a timeline.

Write the chain once. The compiler turns it into CSS keyframes, so the browser does the animating and the file carries no script.

02 Diagrams

Diagrams that build themselves.

Give it nodes and edges. It lays them out, reveals them in order and sends a packet along any route.

03 Code and terminals

Show the code. Run the commands.

A spotlight follows the explanation and a note pins to the token it is about. Terminals print what the real shell prints.

04 Ink and type

Your fonts. Your ink.

Embed a font and it is cut down to the glyphs you use. Write by hand with a brush, a nib or a pencil.

05 Light and dark

One file. It changes its own mind.

lightdark
Point or tap to play

The two halves are the same daynight.svg, fetched once. One <img> is told the page is light, the other that it is dark. The scene decides what to show.

  • A media query inside the fileThe scene carries @media (prefers-color-scheme) rules.
  • Not a recolorThe sun is a moon, windows light up, a beam sweeps the water.
const { theme, css } = adaptive({
  dark: tomorrowNight, light: tomorrow,
});
// theme colors are CSS variables
render({ css }, <rect fill={theme.base00} />);

06 Agents

Agents write scenes too.

Install the skill once. A coding agent then reads it, writes a scene, renders frames, looks at them and fixes what it sees.

07 Without JSX

Not a JSX fan? Use functions.

Every element is also a function. Set prefix and the file can be inlined next to others, in a view library such as FoldKit, without id clashes.

09 Start

Install it, then ask for a scene.

See every exampleWatch the 45 second intro

In a project

npm i svjeez
npx svjeez frames scene.tsx --sheet
npx svjeez svg scene.tsx --out scene.svg

TypeScript, no dependencies, Node 20 or newer.

With a coding agent

npx svjeez skill --install

Copies a skill and worked examples into .claude/skills, so the agent knows how to write, render and check a scene.
