TSX in.
One SVG out.

svjeez compiles a scene written in TSX into a single animated SVG. Motion becomes CSS keyframes, so there is no JavaScript to ship and the file plays in a plain <img>.

$ npm i svjeez See examples GitHub

All of that is one SVG file, 12 KB over the wire. Open it and view source.

How it works

Write a scene, render it, ship an image.

  1. Write the scene

    import { render, draw } from "svjeez";

export default () => render(
  { width: 320, height: 200,
    duration: 4, title: "Arc" },
  <path d="M40 150C100 30 220 30 280 150"
    fill="none" stroke="#E8772E"
    strokeWidth={6}
    animation={draw({ at: 0.3, over: 1.5 })}
  />,
);

    Motions are values on a timeline. They are typed, so a misspelled channel is a compile error.

  2. Render it

    # one file out
npx svjeez svg arc.tsx --out arc.svg

# or look at frames first
npx svjeez frames arc.tsx --sheet

    The compiler emits CSS keyframes, and SMIL for filter primitives. It validates the result, so the file is the whole scene.

  3. Ship an image

    <img src="arc.svg" alt="An arc draws">

    Nothing runs in the viewer's browser. It works anywhere an image does: READMEs, docs, blog posts. Coding agents can write scenes too: npx svjeez skill --install.

Light and dark

One file. It changes its own mind.

The two halves below are the same daynight.svg, fetched once. One <img> is told the page is light, the other that it is dark. The scene decides what to show.

lightdark
  • A media query inside the fileThe scene carries @media (prefers-color-scheme) rules. The page only says which scheme applies.
  • Not a recolorThe sun is a moon, windows light up, a beam sweeps the water. The scene swaps whole parts.
  • Use the toggle at the topIt flips the whole page, and every SVG on it follows.
const { theme, css } = adaptive({
  dark: tomorrowNight, light: tomorrow,
});
// theme colors are CSS variables
render({ css }, <rect fill={theme.base00} />);

Get started

Install it, then ask for a scene.

In a project

npm i svjeez
npx svjeez frames scene.tsx --sheet

TypeScript, no dependencies, Node 20 or newer.

With a coding agent

npx svjeez skill --install

Copies a skill and worked examples into .claude/skills, so the agent knows how to write, render and check a scene.
